## Features

- Interactive drag-and-drop Kanban board
- Columns: Unassigned, To Do, In Progress, Done
- Create, edit, delete tasks
- Priority badges (Low, Medium, High)
- Due date tracking with overdue logic
- Real-time search
- Column counters
- Progress percentage
- localStorage persistence
- Glassmorphism UI

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Docker
- Nginx
- Google Cloud Run
